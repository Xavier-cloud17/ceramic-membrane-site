# 图片替换说明

这个目录保存网站视觉资产。当前版本已经加入三张本地 SVG 示意图：

- `hero-membrane.svg`：首页首屏陶瓷膜组件工业视觉。
- `product-cutaway.svg`：产品中心陶瓷膜截面示意。
- `process-system.svg`：应用和服务页工艺流程示意。

正式上线前建议继续补充真实素材：

- 陶瓷膜元件、膜管截面和组件实拍。
- 实验装置、中试装置、成套系统或工程现场照片。
- 水样处理前后对比图。
- 质检、测试、生产设备和仓储照片。
- 企业微信或销售微信二维码。

替换图片时尽量保持原路径或同步修改 HTML 中的 `src`，避免 GitHub Pages 上出现断图。
