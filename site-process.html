首页搭建流程

Build process

对标雅瓷框架的企业网站搭建流程

本页是流程摘要，完整文档已同步到 GitHub 根目录的 SITE_BUILD_PROCESS.md，便于后续交给团队执行。

01

拆参考站框架

提取导航、首页模块、产品/应用/新闻/招聘/联系栏目和询盘转化路径。

02

建立信息架构

形成首页、关于、产品中心、产品详情、应用、案例、服务、资源、新闻、FAQ、招聘、联系等页面。

03

前端实现

用静态 HTML/CSS/JS 实现响应式、多级导航、产品详情页、CTA、表单、SEO 和站点地图。

04

内容替换

替换公司名称、联系方式、资质、产品参数、真实案例、新闻和下载资料。

05

部署上线

先用 GitHub Pages 验证，后续租服务器后迁移至 Nginx + HTTPS + 域名解析。
